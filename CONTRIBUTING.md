# Contributing

Thank you for your interest in this project!

Please note that this repository is under an **All Rights Reserved** license since I use private ressources. As such, I'm unfortunately not accepting outside code contributions or Pull Requests at this time.

## Reporting Bugs or improvements

- If you find an issue, feel free to open an **Issue** on GitHub.
  - Describe it as much as you can with steps to reproduce.
- Feel free to ask for improvements.
  - Don't ask for your specific cases, unless it's easy to implement and generalize.
- Keep in mind that improving this will take me time/tokens.

## Code of conduct

You will NEVER use or provide paid ressources without the owner's written permission.

## Main goal

The absolute goal is to have this tool easily qualified against IEC / DO178/330.
